# Интерактивный урок математики: Основание и высота треугольника (5 класс)
### Оптимизировано для сенсорных электронных досок (Smart Board / интерактивные панели)

---

## 🚀 Как запустить:
1. Просто откройте файл **`index.html`** в любом браузере (Chrome, Edge, Яндекс Браузер).
2. Нажмите кнопку **⛶ (На весь экран)** в правом верхнем углу (или клавишу `F11`), чтобы развернуть сайт на всю интерактивную доску.
3. Проект полностью **автономен и работает без интернета** (SVG-чертежи, встроенный Web Audio API, холст для маркера).

---

## 🎯 Возможности для электронной доски:
* **✏️ Интерактивный Маркер (Whiteboard Pen):** рисование поверх слайдов стилусом или пальцем (5 цветов, 3 размера пера, ластик, очистить).
* **⏱️ Таймер урока на 45 минут + быстрые пресеты:** 8 мин, 9 мин, 5 мин (под блоки записей в тетрадь).
* **✍️ Окна «Запиши в тетрадь» в клетку:** реалистичный тетрадный лист с красными полями и кнопкой автоматического запуска таймера.
* **⚡ Ультра-быстрый отклик:** отключен 300ms тач-лаг, оптимизирована отрисовка для 4K-досок, убраны тяжелые blur-эффекты.

## 📚 Структура урока (по конспекту на 45 минут):

1. **🏠 Старт:** титульный экран, цели урока, навигация.
2. **Шаг 1 (0–10 мин). Основание и противолежащая вершина:**
   * Метафора фундамента дома (в треугольнике основанием может быть любая сторона!).
   * Интерактивный чертёж △ABC: выбор любого из трёх оснований (BC, AC, AB), автоматическая подсветка красным цветом и выделение противолежащей вершины.
   * Виды треугольников по углам (остроугольный, прямоугольный, тупоугольный).
   * Блок в тетрадь #1 (~8 мин).
3. **Шаг 2 (10–22 мин). Три случая высоты (стр. 91–92 учебника):**
   * а) Прямоугольный △ABC — высота совпадает с боковой стороной AC (AC ⊥ BC).
   * b) Остроугольный △DEF — высота DG лежит ВНУТРИ.
   * c) Тупоугольный △WXY — основание продлевается пунктиром, высота WZ падает СНАРУЖИ!
   * Разбор задания №2 со стр. 92 (△EFG — 3 высоты и ответ на вопрос девочки).
   * Блок в тетрадь #2 (~9 мин).
4. **Шаг 3 (22–32 мин). Проверка угольником и формула площади:**
   * Интерактивный прямоугольный треугольник-угольник (2 правила проверки высоты).
   * Наглядная демонстрация формулы $S = (a \cdot h) : 2$ (треугольник как ровно половина прямоугольника).
   * Периметр $P = a + b + c$ и обратные формулы.
5. **Шаг 4 (32–45 мин). Практикум и рабочая тетрадь:**
   * «Может ли отрезок BD быть высотой?» (разбор 1a и 1b со Скриншота 3).
   * Интерактивные карточки рабочей тетради (Скриншоты 4 и 5) с ловушками!
   * Решение 2 типовых задач для тетради (Блок 3, ~5 мин).
6. **🏆 Супер-Квиз у доски (5 минут):**
   * 5 ключевых вопросов на закрепление темы со звёздами и праздничным салютом!
